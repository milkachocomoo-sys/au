✅ Autism-friendly rules followed on this page

  • Muted palette: no bright, saturated colors — soft sage greens and dusty blues only
  • Off-white background (#f5f2eb): reduces glare compared to pure white
  • No animations or autoplay: nothing moves unless you click
  • prefers-reduced-motion: CSS respects the OS setting
  • Accessible font — Atkinson Hyperlegible: designed for low-vision readers, clear letterforms
  • 18px+ body text, 1.7 line-height: easy to read without strain
  • Single-column layout: one clear path through the page, no overwhelm
  • Icons always paired with text: never icon alone
  • Large click targets (44–48px min): easy to tap on mobile
  • Skip-to-content link: keyboard users can jump past nav
  • Plain language: no idioms, sarcasm, or implied meaning
  • User controls: dark mode + text size toggle — persistent, visible
  • No time limits: the form has no countdown or session expiry
  • Color not the only signal: errors would use icon + text + border — not just red
